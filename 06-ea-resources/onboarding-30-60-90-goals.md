# 🗺️ Onboarding 30-60-90 Goals

## First 30 Days · Learn
- [ ] All access granted and working
- [ ] Inbox and calendar system running daily
- [ ] All Personal / Business / Preferences pages filled out
- [ ] First EOD reports and weekly 1:1s happening

## Days 31–60 · Own
- [ ] Fully own inbox, calendar, travel
- [ ] Manage invoices and subscriptions
- [ ] Executive spends < 15 min/day on admin
- [ ] Document SOPs for repeat tasks

## Days 61–90 · Optimize
- [ ] Take on 1–2 projects from Business Objectives
- [ ] Automate recurring workflows
- [ ] Run quarterly Energy Audit refresh
- [ ] 90-day review with executive
