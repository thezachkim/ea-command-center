# 🧭 EA Onboarding Checklist

> Everything the EA needs to get set up and up to speed. Work top to bottom during week one.

## Week 1 · Access & Setup
- [ ] Sign NDA / confidentiality agreement
- [ ] Get added to password manager (shared vault)
- [ ] Email delegate access set up
- [ ] Calendar delegate access (edit + see private details as agreed)
- [ ] Access to shared drive / docs
- [ ] Access to Slack / team chat
- [ ] Access to task & project tools
- [ ] Access to expense / invoicing tools
- [ ] Phone / messaging channel agreed for urgent items
- [ ] Set up EA email signature

## Week 1 · Learn the Executive
- [ ] Complete [Client Onboarding Checklist](client-onboarding-checklist.md) with the executive
- [ ] Read [Core Values, Mission & Vision](../03-business-information/core-values-mission-vision.md)
- [ ] Review [Company Information & Products](../03-business-information/company-information-and-products.md)
- [ ] Review [Stakeholders](../03-business-information/stakeholders.md) list: who's VIP, who's gatekept
- [ ] Fill out [General Information & Preferences](../04-client-preferences/general-information-and-preferences.md)
- [ ] Complete [Energy Audit](../04-client-preferences/energy-audit.md) together

## Week 2 · Take Over Workflows
- [ ] Run inbox triage solo using [Inbox Management](../04-client-preferences/inbox-management.md) rules
- [ ] Own calendar scheduling end to end
- [ ] Book first trip using [Travel Management](../04-client-preferences/travel-management.md) preferences
- [ ] Send first [EOD report](../08-daily/reports.md)
- [ ] Hold first weekly [1:1](../07-weekly/one-on-one-meetings.md)
- [ ] Set up recurring reminders for [Important Dates](../02-personal-information/important-dates.md)

## Week 3–4 · Optimize
- [ ] Audit [Subscription List](../06-ea-resources/subscription-list.md) and flag waste
- [ ] Propose 3 process improvements
- [ ] Review [30-60-90 Goals](../06-ea-resources/onboarding-30-60-90-goals.md) progress
- [ ] Collect feedback on the [Feedback Page](../05-client-workspace/feedback-page.md)
