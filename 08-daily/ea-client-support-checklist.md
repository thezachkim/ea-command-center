# 🔄 EA Client Support Checklist

> Run this every day. Reset the boxes each morning.

## Morning
- [ ] Check inbox + triage (Action / Waiting / EA Handling)
- [ ] Review today's calendar, confirm meetings
- [ ] Prep briefing docs for today's meetings
- [ ] Check messages / Slack for overnight requests
- [ ] Review Task Board priorities

## Midday
- [ ] Second inbox sweep
- [ ] Follow up on 'Waiting' items
- [ ] Update tasks on Task Board

## End of Day
- [ ] Inbox zero
- [ ] Send EOD report
- [ ] Prep tomorrow's calendar briefing
- [ ] Log hours
- [ ] Check Important Dates for upcoming reminders

## Weekly (Fridays)
- [ ] Send EA Hours Report
- [ ] Prep 1:1 agenda
- [ ] Review next week's calendar
- [ ] Check subscriptions renewing soon
